
# E-Commerce Sales Analytics

An end-to-end e-commerce sales analytics project using Python and Power BI.

## Project Overview

This project analyzes the Olist Brazilian E-Commerce dataset to explore sales performance, customer insights, product category performance, and delivery operations.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Power BI
- DAX
- Git & GitHub

## Project Workflow

1. Data inspection
2. Data quality analysis
3. Data cleaning
4. Data integration
5. Exploratory data analysis (EDA)
6. Power BI data modeling
7. DAX measures and KPI development
8. Interactive dashboard development

## Dashboard

The Power BI dashboard includes:

- Total Revenue
- Average Order Value
- Average Review Score
- Delivery Rate
- Monthly Revenue Trend
- Top 10 Product Categories by Revenue
- Monthly Late Delivery Rate
- Order Status Distribution

## Data Source

Olist Brazilian E-Commerce Public Dataset — Kaggle.

The original dataset is not included in this repository. Please refer to the dataset source and its applicable license before using it.

## Repository Structure

- `src/`: Python scripts for data processing and analysis
- `data/`: Local raw and processed datasets (not tracked)
- `powerbi/`: Power BI dashboard
- `reports/`: Exported analysis results
- `screenshots/`: Dashboard preview
